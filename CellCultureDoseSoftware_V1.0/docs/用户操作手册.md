# 用户操作手册（V1.0）

## 1. 首次使用

1. 双击 启动软件.bat。新数据库首次启动显示设备配置，可填写反应器、泵、补料液和设备读数单位；选择“稍后设置”后可从“资料与设置”继续。
2. 进入“基础数据”，确认泵编号与 Dose Monitor 导出中的泵编号一致；按需维护组分、工艺液和反应器。
3. 进入“配方管理”，新建配方并添加组分明细；确认无误后点击“发布 / 停用”发布。
4. 进入“批次管理”，新建批次；创建后系统自动生成“接种 / 培养 / 收获”三个阶段，可按实际修改。
5. 在批次详情的“泵 - 液体绑定”中，为每个泵绑定本批次实际使用的液体。

## 2. 配制计算

1. 进入“配制计算”，选择配方版本和关联批次（可选）。
2. 输入目标体积、体积单位；如需记录实际称量，填写实际称量总量与实际定容体积。
3. 点击“计算预览”，核对理论用量、纯度修正量、母液体积和定容补足量。
4. 确认后点击“保存配制记录”；系统保存不可变的组分明细快照。
5. 选中历史记录后可导出称量清单（Excel）。

## 3. 补料计划

1. 进入“补料计划”，选择当前批次。
2. 点击“新建版本”；如已有计划，会复制上一版本事件作为草稿。
3. 点击“新增事件”，选择阶段、液体、泵，填写计划开始/结束、计划量、目标流速；时长留空时自动按计划量 ÷ 流速计算。
4. 右侧“计划检查”会提示同一泵时间重叠或同泵不同液体；确认后点击“确认计划”。
5. 已确认计划不能直接修改，应创建新版本。

## 4. 泵校准

### 手工录入

1. 选择泵，点击“手工新建校准”。
2. 每行输入：设置值, 实测流速, [设置值单位], [流速单位]，至少 2 行。
3. 保存后状态为“待审核”；核对后点击“设为有效”。

### 导入 my-Control 文件

1. 选择泵，点击“导入 my-Control”。
2. 选择 CSV/XLSX 文件，确认工作表与表头行；系统自动匹配字段，可手动调整。
3. 点击“预览解析结果”，检查校准点与错误/警告。
4. 填写校准日期与备注，点击“保存校准记录”。

校准曲线只在实测点覆盖范围内插值；超出范围时不会外推。

## 5. Dose Monitor 数据导入

1. 在顶部选择目标批次，进入“剂量导入”，点击“开始导入”。
2. 第 1 步：添加一个或多个 CSV/XLSX 文件。
3. 第 2 步：选择工作表和表头行（可自动识别）。
4. 第 3 步：确认时间戳、泵编号等字段映射；时间戳和泵编号为必填映射。
5. 第 4 步：检查标准化数据预览、行数、时间范围、错误和警告；存在阻断错误时不能继续。
6. 第 5 步：填写备注，确认导入；系统归档原文件并保存标准化数据。

## 6. 设备估算剂量核算

### 手工记录设备屏幕读数

1. 选择进行中的批次，进入“补料记录”，点击“开始 / 结束补料”。选择泵和补料液，可选择关联计划事件，也可选择计划外。
2. 开始时输入开始时间、设备开始读数及单位，点击“开始补料”。结束时选择该记录，点击“载入所选记录”，填写结束时间与读数后点击“保存结束 / 更正”。也可在结束后一次填写并保存完整记录。
3. 如有独立测量，另填实测量、单位及测量方法；没有时留空。设备估算值并非独立测量值。已知本次期间发生归零时勾选归零选项。
4. 填写泵型号、控制连接与校准等已知信息。缺失读数、时间错误或读数下降的记录可保存，状态为待审核，不自动给出估算量。双击历史记录查看原始值和原因。
5. Excel/PDF 批次报告包含手工记录。实际泵、控制通道和校准系数需在设备接入后现场确认。

“补充信息”中可填写中途读数（每行“时间,读数”）、独立实测和备注。完成记录更正时需填写操作人和原因，修改前后记录可双击历史行查看。无法完成的进行中记录应选择“标记未完成”并填写原因，再结束批次。

软件允许同时有一个进行中批次；如旧数据已有多个进行中批次，首页会提示逐一处理，软件不会自动关闭或删除它们。

导入文件中没有单位列或带单位的数值时，必须在字段映射页面明确选择单位。历史核算记录的来源无法确认时显示“来源待核实”。

1. 进入“剂量核算”，选择泵；可选择补料事件自动带入时间窗口和计划量。
2. 点击“运行核算”，查看设备估算量、流速积分、偏差量、偏差率、完成率，以及流速/累计体积趋势图。
3. 查看“数据质量与异常”：计数器重置、采样断点、重复时间或方法差异会标记为“待审核”。
4. 点击“保存核算结果”；系统保存核算版本，并将异常写入“异常审核”。

## 7. 异常审核

1. 进入“异常审核”，按当前批次/全部批次和状态筛选。
2. 选中异常，查看描述与关联信息。
3. 点击“解决选中异常”，填写核查结论、修正措施或确认依据；原始导入记录不会被覆盖。

## 8. 报告中心

1. 选择批次，进入“报告中心”。
2. 点击“生成 Excel 报告”或“生成 PDF 报告”。
3. 报告包含批次概况、阶段与参数、配方与配制、补料计划、泵校准、剂量核算、数据导入、异常记录。
4. 报告历史按批次和类型递增版本；可打开报告或所在文件夹。

## 9. 备份与恢复

1. 进入“系统设置”，点击“立即备份”；备份文件保存在 ApplicationData/backups/。
2. 选中备份，点击“校验选中”检查 ZIP 和数据库完整性。
3. 点击“恢复选中”，系统先自动创建恢复前备份，再替换数据库并合并导入文件/报告；恢复后软件自动重启。
4. 恢复是有覆盖性的操作，请确认当前数据已备份。

## 10. 常见问题

- 启动时提示找不到 Python：安装 Python 3.10+ 并勾选 Add Python to PATH，然后运行 pip install -r requirements.txt。
- Excel/PDF 报告生成失败：确认已安装 openpyxl、reportlab；PDF 需要 Windows 中文字体（微软雅黑/黑体/宋体）。
- 导入提示泵编号未知：到“基础数据 → 泵”新增对应泵编号，或在导入映射中确认泵编号列。
- 核算结果为“待审核”：查看“数据质量与异常”，确认计数器重置、采样断点或时间窗口后再决定是否接受。
- 计划无法修改：已确认计划应创建新版本后修改。
